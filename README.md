A make.fun bounty entry: one funny passive-aggressive note a smart fridge
leaves for its owner, written by a program (`main.ts`, Node 22, standard
library only) to `/output/entry.txt`.

## The note

> Your leftovers from March have unionised. They have negotiated weekends
> off, and they no longer answer to 'dinner'.

## Run it

```sh
node main.ts
# writes entry.txt to $MAKEFUN_OUTPUT_DIR (default /output)
```
